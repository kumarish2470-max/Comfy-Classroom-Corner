Classroom Wellness Nook 🌿✨

A 3D architectural visualization of a student wellness corner designed for social-emotional learning (SEL) within a standard classroom environment.

📖 Overview

The Classroom Wellness Nook is an interactive 3D prototype that visualizes how a small corner of a classroom (approx. 4ft x 4ft) can be transformed into a functional mental health resource.

This project demonstrates the integration of a "recharge zone" featuring comfort seating, biophilic design elements, and privacy features, all situated within a fully rendered classroom context.

🌟 Key Features

1. The Nook (Wellness Corner)

Comfort Seating: Plush bean bag chair, round rug, and throw cushions for relaxation.

Privacy System: L-shaped curtain rod with interactive privacy curtains that can be opened or closed.

Resource Library: Wooden bookshelf fully stocked with colorful books and a visible first-aid kit (Medikit).

Biophilic Design: Leafy potted plants placed on the floor and shelves to promote calm.

Utilities: Wall-mounted charging station for student devices.

Decor: Motivational signage ("Prioritize Your Peace", "Positive Vibes") and a mindfulness whiteboard.

2. The Classroom Environment

Full Context: The Nook is placed in the back-right corner of a standard classroom layout.

Standard Equipment: Includes student desks, teacher's podium, green chalkboard, and a wooden entry door.

Lighting Logic: * Global Light: Bright, standard classroom lighting always active for safety.

Local Light: Warm fairy lights inside the Nook that can be toggled independently.

🎮 Interactive Controls

The simulation features a UI panel for easy interaction:

Control

Action

Toggle Nook Lights ✨

Switches the warm fairy lights on/off (does not dim the main room).

Privacy Curtains 🚪

Opens or closes the curtains around the Nook.

View: Full Class 🏫

Moves camera to show the entire classroom layout.

View: Door Area 🚪

Focuses on the classroom entrance.

Zooms into the wellness corner.

Mouse Controls:

Left Click + Drag: Rotate view

Right Click + Drag: Pan view

Scroll: Zoom in/out

🛠️ Technology Stack

HTML5 / CSS3: Structure and UI styling.

JavaScript (ES6): Core logic.

Three.js: 3D rendering engine.

Procedural Textures: Custom canvas-based texture generation for wood, rugs, and signage (no external image assets required).

🎨 Design Concept

This project translates a hand-drawn concept sketch into 3D. It focuses on the following design principles for student wellness:

Separation: Visual boundaries (curtains) to reduce sensory overload.

Softness: Replacing hard plastic furniture with fabrics and cushions.

Nature: Bringing outdoors in with plants.

Agency: Allowing students to control their privacy and lighting.
